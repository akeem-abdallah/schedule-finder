Five themes for the board

Same structure throughout — status strip, ruled table, mono data, 12-hour times in the gutter. Only the token values change. Each shown light and dark.

1 — Amber  ·  departure board

Warm off-white and warm black, burnt-amber accent. The one you already saw, tightened. Reads like a station board; the warmth keeps it from feeling clinical.

4 — Terminal  ·  phosphor green

Dark-native: green on near-black, the way a CS student's editor already looks. The light variant is "printout" — cream paper, dark green ink. Most personality of the five and the most on-the-nose for who built it. Risk: it can read as costume rather than design, and green-on-black is genuinely harder to read for long stretches.

Shared across every theme — the eight course hues

These don't change per theme. Each is one hex; the fill is that hex at ~11% on light and ~26% on dark, and the block text always uses the theme's own text color. That's why eight courses cost eight values total, not eight per theme.

#2f6bff #e0561f #17a06a #9d4edd #c9910d #00a0b8 #e0447f #7cb518
One decision left

Because every theme is the same token names with different values, shipping several is nearly free once the first one is written — a second theme is one extra [data-theme="x"] block, no markup changes. The real cost isn't CSS, it's the switcher UI and remembering the choice in localStorage.
